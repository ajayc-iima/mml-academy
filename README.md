# MML Academy 🍰

An interactive, self-contained learning app for **Mathematics for Machine Learning**
(Deisenroth, Faisal & Ong, 2020) — every concept in five layers:

- 🍰 **Intuition** — plain-English first, jargon second
- 🧮 **The mathematics** — proper theorem statements, beautifully typeset
- 🤖 **Where ML uses it** — mapped to modern systems (attention, diffusion, LoRA, VAEs…)
- ✍️ **Solve it by hand** — 57 step-by-step workouts: attempt each step before revealing it
- 🏋️ **Practice** — 59 problems with hidden full solutions

Plus 5 interactive widgets (eigenvectors, gradient descent, least squares, PCA, EM),
a searchable formula vault, progress tracking, and a research roadmap from this
book to pure-math ML research.

## Run it

No build, no dependencies, works offline — just open `index.html` in any browser.
